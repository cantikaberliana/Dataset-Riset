# Riset Informatika: UTS

**Pengembangan Model Klasifikasi Gejala GERD dan Anxiety Menggunakan Explainable Machine Learning**

Klasifikasi gejala (normal, GERD, anxiety, GERD+anxiety) dengan Logistic Regression, Random Forest, dan XGBoost, dijelaskan memakai SHAP.

> Proyek akademik. Bukan alat diagnosis medis.
